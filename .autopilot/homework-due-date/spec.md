# Автозаполнение срока
Новое ДЗ: ближайшая дата предмета из расписания текущего класса строго после сегодняшнего дня (1..7 календарных дней). Совпадение предмета без учёта регистра и лишних пробелов, подсказки из расписания. Локальная дата пользователя, без UTC-сдвига.
Изменённый вручную срок не перезаписывается. При редактировании сохраняется срок существующего ДЗ. Если урок не найден или расписание не загрузилось — ручной ввод доступен, без выдуманной даты. Изоляция классов и поздних ответов. Схема/сервер не меняются.
Проверки: календарные границы и ближайший урок, browser автоподстановка/manual/edit, полная suite/build, независимыйreview. Обновление Fly/GitHub в рамках существующей поставки.
