# Изменение расписания
R01: убрать ввод номера в форме создания/редактирования урока; сервер автоматически добавляет урок в конец выбранного дня.
R02: учитель меняет порядок внутри дня перетягиванием мышью/касанием, доступно клавиатурное управление. После сохранения все роли видят тот же порядок и время звонка соответствующего слота.
Порядковые номера сохраняются в существующей lesson_number, без миграции схемы. При изменении дня урок попадает в конец нового дня; удаление и перенос уплотняют старый день. Максимум20 уроков. Старые записи/ID/предметы/кабинеты сохраняются.
Атомарный PUT /api/classes/:id/lessons/order принимает dayOfWeek и полный lessonIds. Учитель только своего класса; reject duplicates/foreign/missing IDs. Родители/ученики readonly. Ошибка сохранения не показывает ложный успех; повторный POST не создаёт дубликат после успешной записи с неудачным refresh.
Проверки: HTTP порядок/права/невалидные запросы/20уроков/старые пробелы/rollback, сборка, desktop и mobile UI. Обновить существующий Fly.io и GitHub в рамках ранее разрешённой поставки; без изменений production-данных QA.
