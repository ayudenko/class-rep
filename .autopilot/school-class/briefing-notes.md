# Брифинг: подтверждённое и открытое

## Подтверждено пользователем
- Нужны веб-версия и мобильное приложение.
- Нужны реальные аккаунты; локальная имитация ролей не удовлетворяет запросу.
- Исходные возможности остаются обязательными (R01–R12i).

## Вопрос подтверждён
Способ регистрации и входа: рекомендуемый вариант — email и пароль для взрослых, отдельные логины для учеников; учитель приглашает родителя к конкретному ребёнку. Пользователь ответил «Подходит»; альтернативы отклонены выбором рекомендуемого варианта.

## Принятые рабочие решения
- Состав анкеты: минимальная расширяемая форма — ФИО, дату рождения, контакты родителей, заметку учителя; не добавлять медицинские сведения и адрес без запроса.
- Размещение: собственный сервер или существующий облачный сервис; до ответа можно подготовить сервер, базу и локальный запуск без платного провайдера, но нельзя выдавать это за доступный извне сервис.

## Инварианты реализации
- Проверять доступ на сервере при каждом запросе; клиентский переключатель роли не является авторизацией.
- Учитель управляет только своими классами; ученик — своим выполнением; родитель получает доступ только к связанным детям.
- Анкетные сведения недоступны другим ученикам/родителям.
- Самостоятельная отметка выполнения и учительская оценка качества — разные события.
- Повторный запрос или снятие/возврат отметки не дублирует награду.
- Удаление или перенос задания не должно незаметно менять уже выданные награды.
- Пустой класс, отсутствие ДЗ, ошибка сохранения и потеря соединения имеют явные состояния.
- Пароли хешируются; сессии отзываются; секреты не попадают в репозиторий.

## Среда
Есть Node 25.2, npm 11.6.2, Xcode 26.6 и Python 3. Java не найдена. Проверка Android-сборки потребует JDK и Android SDK. Доступ к локальному порту в текущем sandbox ранее отклонён; потребуется предусмотренная средой эскалация для запуска и проверки сервера.

## Независимая проверка архитектуры
Агент architecture_check рекомендует React + TypeScript + Vite + Capacitor 8 и Node/SQLite REST API. Адаптивный интерфейс общий для веба и мобильных контейнеров; это не отдельный React Native UI. Capacitor: https://capacitorjs.com/docs/basics/workflow . Требования окружения: https://capacitorjs.com/docs/getting-started/environment-setup . Локальные версии Node и Xcode подходят. Android Studio может содержать встроенный JDK; отсутствие java в PATH не доказывает отсутствие JDK на диске. iOS Simulator требует установленного runtime; developer-аккаунт для симулятора не обязателен. Android-компиляция ещё не проверена. Docker 29.4.0 доступен как команда; daemon не проверен.

Серверная рекомендация: роли на уровне членства в классе, персональные одноразовые приглашения родителей, scrypt/Argon2id, отзываемые сессии и ограничение входов. Для веба HttpOnly cookies с CSRF-защитой, для мобильного клиента системное защищённое хранилище. Идемпотентность наград — транзакции и уникальные ограничения в БД. Это предварительное техническое решение; пользовательские правила входа ещё ожидают ответа.
