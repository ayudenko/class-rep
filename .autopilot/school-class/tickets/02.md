# 02 — Расписание уроков и звонков

Требования: R05, R06
Blocked by: ['01']
Волна: 2
Зона: server/schedule.mjs, src/features/schedule, tests/schedule.test.mjs

## Из брифа
«мобильное приложение для школы»; «веб версию и приложение, с реалными аккаунтами»; «список учеников и их анкетные данные, расписание уроков, звонков»; «домашние задания»; «получать ачивки, баджи»; «Учитель тоже может выдавать награды».

## Разделы спецификации
Истории и приёмка (указанные требования), Реализация, Границы и швы.

## Что должно заработать и критерии приёмки
Реализуй весь путь расписания в своей зоне на общей основе T01: учитель создаёт/редактирует/удаляет уроки по дням недели и звонки, роли ученика/родителя только читают доступный класс. Проверяй уникальность слота day+lesson number, корректное время, начало<конец и отсутствие пересечений звонков. UI: недельная навигация по дням, карточки/строки уроков с номером, предметом, временем по звонкам, кабинетом; управление звонками учителем, пустые/ошибочные состояния. Вписать в стили T01, не менять общий CSS без запроса (можно свой CSS). API tests полноценных сценариев включая чужие classId/itemId, parent/student write forbidden, конфликт слотов/интервалов. Не меняй shared files/schema: если нужно сообщи. Критерии: CRUD уроков; CRUD звонков; все роли читают только свои классы; запрещённые изменения/чужие записи дают отказ; ошибки валидируются и не теряют форму; npm test/build зелёные. Читать core-contract.md от T01.
