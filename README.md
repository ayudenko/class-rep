# Классно

Русскоязычное пространство школьного класса: реальные аккаунты учителя, учеников и родителей, анкеты, расписание, домашние задания и награды. React/TypeScript + Node/Express + SQLite, iOS и Android на Capacitor 8. Название рабочее.

## Локальный запуск

Нужен Node.js >=22.13 и npm.

```sh
npm ci
npm run dev
```

Откройте http://localhost:5173 (именно localhost). API слушает 127.0.0.1:3000. База создаётся в `data/klassno.sqlite`. Демоаккаунтов нет. Создайте аккаунт учителя, затем класс и ученика. Передайте ученику его логин и начальный пароль лично; смена пароля находится в профиле. Для родителя создайте приглашение в анкете, передайте ссылку лично. Родитель открывает ссылку, регистрируется или входит, затем принимает приглашение. Ссылка действует 48 часов и используется один раз. У родителя может быть несколько детей.

```sh
npm test
npm run build
npm start
```

После сборки `npm start` отдаёт интерфейс и API на http://localhost:3000. Без NODE_ENV=production это локальный режим с cookie без Secure. При закрытии native приложения потребуется повторный вход: bearer хранится только в памяти.

## Один production-сервер

Нужны выбранный вами домен, HTTPS reverse proxy и постоянный том для базы. Публичное размещение и публикация в магазинах не выполнялись. Веб использует API того же origin, поэтому **при веб-сборке оставьте VITE_API_URL пустым**. Не используйте native dist для веб-развёртывания.

```sh
docker build -t klassno .
docker volume create klassno-data
docker run -d --name klassno --restart unless-stopped \
  -p 127.0.0.1:3000:3000 -v klassno-data:/data \
  -e ALLOWED_ORIGINS='https://YOUR-DOMAIN,capacitor://localhost,http://localhost' \
  -e PUBLIC_URL='https://YOUR-DOMAIN' klassno
```

Замените YOUR-DOMAIN реальным доменом. Reverse proxy должен завершать TLS и перенаправлять на 127.0.0.1:3000. Production cookie имеет Secure/HttpOnly/SameSite=Lax. ALLOWED_ORIGINS — список точных origins без завершающего `/`, wildcard не используется; если список не задан, изменяющие запросы отклоняются. Native origins нужны для токена в памяти. Не публикуйте порт базы, не запускайте несколько серверов на одной SQLite базе. Для резервной копии остановите контейнер и сохраните весь том; восстановление делайте при остановленном сервере. Проверьте регистрацию/вход через HTTPS до выдачи доступа.

`.env.example` описывает переменные. `npm start` сам `.env` не читает: экспортируйте значения или выполните `node --env-file=.env server/index.mjs`. Не копируйте шаблон production настроек в локальный запуск без изменения значений.

## Восстановление доступа

Администратор сначала проверяет личность владельца вне приложения, затем на сервере выполняет:

```sh
DB_PATH=/path/to/klassno.sqlite PUBLIC_URL=https://YOUR-DOMAIN npm run reset-password -- USER_LOGIN
# В контейнере:
docker exec -it klassno npm run reset-password -- USER_LOGIN
```

Команда выводит секретную одноразовую ссылку (1 час). Передайте её владельцу лично, не сохраняйте в общих логах/чатах. После сброса все сессии отзываются. Отправка email не имитируется, SMTP не требуется.
