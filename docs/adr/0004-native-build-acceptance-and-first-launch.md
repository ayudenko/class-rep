# ADR 0004 — Частичная мобильная приёмка при незавершённой настройке Xcode

## Контекст

R01/G01 требуют успешных native builds; исходный проект сам по себе не закрывает поставку приложения. В спецификации зафиксирован D01: iOS SDK присутствует, но отсутствует системный CoreSimulator.framework, а checkFirstLaunchStatus возвращает 69. Манифест оставляет R01/G01/D01 в состоянии placeholder.

## Решение

Сохранить iOS-бинарник как незакрытое требование до действия владельца Mac и повторной проверки сборки. Не выполнять от имени владельца runFirstLaunch, поскольку штатная команда совмещает установку компонентов с принятием лицензии. Отдельно фиксировать успешную локальную Android debug сборку, отсутствие проверки native runtime и ещё не выбранный публичный HTTPS origin.

## Почему

Наличие SDK не подтверждает возможность компиляции, а исходный native проект не равнозначен бинарнику. Объявление полной готовности по веб-сборке или Android APK скрывало бы незакрытую iOS часть. Автоматическое принятие лицензии не является необходимым техническим решением агента: завершение первоначальной настройки требует действия владельца Mac. Отказ от iOS также не подходит — снять исходное требование может только пользователь.

## Последствия

R01/G01 остаются частично выполненными. После завершения владельцем настройки Xcode необходимы повторная iOS сборка и отдельная проверка запуска приложения. Локальный Android debug APK не подтверждает доступность публичного сервера или готовность магазинного релиза. Публичное размещение, подпись и публикация остаются отдельными внешними условиями, а не объявляются выполненными.
